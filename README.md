# MultiChatWindows (Fabric 1.21.10)

Client-side mod: multiple chat windows with per-server tabs and a Mod Menu configuration screen.

## Requirements

- Minecraft 1.21.10
- Java 21
- Fabric Loader
- Fabric API
- Mod Menu
- Cloth Config API

## Build

```bash
gradle clean build
```

The built jar is created in `build/libs/`.

## Icon

The included mod icon is located at `src/main/resources/assets/multichatwindows/icon.png`.

## Config files

Stored in `config/multichatwindows/`.
